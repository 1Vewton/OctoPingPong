# 标准乒乓球拍技术参数基线报告

## 1 引言

本报告旨在系统记录标准乒乓球拍的技术参数，作为 Octo 乒乓球拍设计的对比基线。通过整理国际乒乓球联合会（ITTF）的器材规格规定、主流品牌（Butterfly、Stiga 等）代表性底板的物理参数，以及标准套胶的重量数据，为后续的轻量化设计（目标总重 110–130 g）提供量化参考基准。

报告涵盖以下内容：
- ITTF 及国家标准对乒乓球拍的规格要求
- 主流底板的尺寸、重量、厚度及结构参数
- 标准套胶（胶皮+海绵）的重量数据范围
- 成品球拍的典型总重与重量分布
- 球拍重心（平衡点）的行业基准

## 2 ITTF 及国家标准规格

### 2.1 ITTF 竞赛规则（2025 版）

根据国际乒乓球联合会《乒乓球比赛规则》第 2.4 条，球拍的相关规定如下[^1]：

| 项目        | 规定内容                                                           |
| :-------- | :------------------------------------------------------------- |
| 尺寸与形状     | 球拍的大小、形状及重量均无限制，但底板应平坦、坚硬                                      |
| 木材比例      | 底板厚度至少应有 85% 的天然木料                                             |
| 纤维层限制     | 底板内层可由碳纤维、玻璃纤维或压缩纸等物料黏合而成，但每层均不能超过底板总厚度的 7.5% 或 0.35 mm（两者取其小） |
| 胶皮厚度（颗粒胶） | 颗粒向外的普通颗粒胶，连同粘合物在内总厚度 < 2.0 mm                                 |
| 胶皮厚度（海绵胶） | 海绵胶连同粘合物在内总厚度 < 4.0 mm                                         |
| 颗粒密度      | 每平方厘米 ≥ 10 粒，≤ 30 粒（颗粒胶）                                       |
| 胶皮颜色      | 双面贴胶皮时两面颜色不能相同，必须一面红色、一面黑色                                     |
| 表面光泽度     | 底板和胶皮的表面光泽度均须 < 24 度                                           |

### 2.2 中国国家标准

GB/T 23115-2008《乒乓球拍》规定了竞赛、练习用乒乓球拍的分类、要求与试验方法[^2]。GB/T 9831-1988（已作废但具参考价值）曾将球拍分为优等品、一等品、合格品，并规定了胶粒几何参数、粘合力等检测方法。

### 2.3 行业标准

T/STIC 110004-2021《专业竞赛乒乓球拍、套胶及底板》进一步细化了专业竞赛用器材的技术要求[^3]。

## 6 重心（平衡点）基准

### 6.1 重心位置测量方法

重心平衡点的测量方法为：将底板平放在垂直立起的直尺边沿上，使拍柄方向与直尺保持垂直，找到平衡点后测量该点到板头顶端的长度，除以底板全长，得到重心百分比[^13]。

### 6.2 行业参考范围

| 球拍类型 | 重心位置（距拍头顶端） | 百分比范围 |
| :------- | :--------------------: | :--------: |
| 单面直拍 | 43%–46% 全长 | 拍头较重 |
| 双面直拍 | 46%–50% 全长 | 重心偏中 |
| 横拍（双面） | 46%–50% 全长 | 重心偏中 |
| **异常范围（拍头过重）** | **< 43%/46%** | 操控困难 |
| **异常范围（拍头过轻）** | **> 46%/50%** | 力量不足 |

> **表 5：标准球拍重心范围**

对于全长约 257 mm 的标准横拍（拍面 157 mm + 手柄 100 mm），46%–50% 的重心位置对应距拍头顶端约 **118–128 mm**，即重心位于拍面与手柄交界附近偏拍头一侧。

## 8 结论

本报告建立了标准乒乓球拍的技术参数基线，主要结论如下：

1. **底板重量基线**：标准横拍底板重量集中在 **82–95 g** 范围，最具代表性的 Butterfly Viscaria 约 88 g。Octo 设计目标需将底板重量降至 55–70 g，降幅约 25%–35%。

2. **成品球拍总重基线**：标准配置总重范围为 **170–200 g**，其中底板约占 46%，两面套胶各占约 26%。Octo 目标总重 110–130 g 意味着各部件均需大幅减重。

3. **握柄尺寸基线**：标准横拍握柄长约 100 mm、周长约 85–95 mm。Octo 握柄需缩短至 60–75 mm、周长缩减至 65–80 mm，以适应掌宽 <7 cm 的用户。

4. **重心位置基线**：标准横拍重心位于距拍头顶端 46%–50% 全长位置。Octo 需通过材料选择与结构设计将重心向拍柄方向移动，以降低转动惯量。

5. **ITTF 合规基线**：ITTF 对球拍尺寸和形状无限制，但对木材比例（≥85%）、纤维层厚度（≤7.5% 或 0.35 mm）、胶皮厚度（≤4.0 mm）等有明确规定，Octo 设计需在规则框架内进行。

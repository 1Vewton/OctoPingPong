# 乒乓球拍底板材料研究报告

## 1 引言

乒乓球拍底板的结构与材料选择直接影响球拍的速度、旋转、控制及手感等核心性能。根据国际乒乓球联合会（ITTF）的规定，竞技用乒乓球拍的底板中，天然木材按厚度占比不得低于 85%，其余不超过 15% 的部分可由碳纤维、芳基纤维、玻璃纤维等合成材料构成，每层粘合层厚度不超过底板总厚度的 7.5% 或 0.35 mm[^1]。

本报告系统梳理了乒乓球拍底板常用天然木材与合成纤维材料的种类、特性及典型应用结构，为 Octo 乒乓球拍的材料选型与结构设计提供技术参考。报告涵盖的内容包括：**天然木材种类**（桧木、桐木、阿尤斯、林巴、蔻头等）、**合成纤维材料**（碳纤维、芳基/芳纶纤维、Zylon 纤维、玻璃纤维等）、**常见层数结构**（纯木五夹/七夹、3+2 碳板、5+2 芳碳板）以及**纤维内置/外置**对性能的影响。

## 2 天然木材种类与特性

乒乓球底板中使用的天然木材按其结构位置可分为**面材（Outer/Veneer）**、**力材（Intermediate Ply / Secondary）** 与**芯材/大芯（Core）** 三类。不同木材因其密度、弹性模量、硬度、纹理等物理性质的差异，适用于不同的层位[^2]。

### 2.1 桧木（Hinoki / Japanese Cypress）

- **学名**：*Chamaecyparis obtusa*
- **产地**：日本、台湾阿里山、北美
- **特性**：质轻、弹性大、韧性好、纹理直且细腻
- **密度**：约 0.40–0.50 g/cm³
- **典型用途**：面材、单桧板（1 层）、芯材
- **适用打法**：弧圈快攻

桧木因其优异的弹性和柔和的击球手感，被日本底板厂商（如 Butterfly、Darker）广泛使用，常见于高档底板的面板和芯板。**单桧板（1-ply Hinoki）** 是直板单面弧圈打法的经典选择[^3]。

### 2.2 桐木（Kiri / Paulownia）

- **学名**：*Paulownia tomentosa*
- **产地**：中国、日本、东南亚
- **特性**：材质轻软、强度适中、生长迅速、透板性好
- **密度**：约 0.25–0.35 g/cm³
- **典型用途**：大芯（Core）
- **适用打法**：进攻型底板（与纤维搭配）

桐木是当今乒乓球底板中使用最广泛的芯材，尤其常见于碳素/芳碳底板。其质感轻软的特点可有效降低底板总重量，同时提供良好的持球感。随着技术发展，**青桐木（Green Kiri）** 因其纤维排列更紧密、支撑性更佳，已逐渐取代传统毛桐木成为主流大芯材料[^4]。桐木大芯搭配外置芳碳（ALC）的组合在 40+ 塑料球时代表现最为强势，代表底板包括 Butterfly Viscaria、樊振东 ALC 等。

### 2.3 阿尤斯（Ayous / Obeche）

- **学名**：*Triplochiton scleroxylon*
- **产地**：西非
- **特性**：木材细腻、弹性优良、比桐木稍重
- **密度**：约 0.35–0.45 g/cm³
- **典型用途**：力材、大芯
- **适用打法**：弧圈/全能型

阿尤斯是典型欧洲底板的芯材选择（如 Stiga OC、Clipper Wood 等），因其良好的形变能力和 "底劲"，尤其受到弧圈型选手的青睐。与桐木相比，阿尤斯大芯的形变更强，出球弧线更饱满，适合强调旋转的打法[^5]。

### 2.4 林巴（Limba）

- **学名**：*Terminalia superba*
- **产地**：西非
- **特性**：木纹细腻、韧性好、触球感柔和
- **密度**：约 0.45–0.55 g/cm³
- **典型用途**：面材
- **适用打法**：弧圈/控制型

林巴是欧洲底板中最经典的面材之一，代表型号包括 Stiga OC 和 Butterfly 科贝尔等。其材质较软、纤维长，能提供优秀的持球感与旋转制造能力，适合近中台弧圈打法。

### 2.5 蔻头（Koto）

- **学名**：*Pterygota macrocarpa*
- **产地**：东南亚、非洲
- **特性**：质地硬脆、纤维长、比重较大
- **密度**：约 0.55–0.65 g/cm³
- **典型用途**：面材
- **适用打法**：快攻/快弧

蔻头因其硬度较高、出球干脆迅速的特性，常用于进攻型底板的面材。典型代表包括 Butterfly Viscaria、波尔 Spirit 等。蔻头面材搭配芳碳纤维可提供凌厉的出球速度和清晰的手感反馈[^6]。

### 2.6 其他常见木材

| 木材名称 | 产地 | 特性 | 典型用途 | 密度 (g/cm³) |
| :------- | :--- | :--- | :------- | :----------: |
| 云杉（Spruce） | 欧洲 | 纹理均匀、弹性好 | 力材 | 0.40–0.50 |
| 白蜡木（Ash） | 欧洲 | 硬度高、出球脆 | 面材 | 0.60–0.70 |

## 3 合成纤维材料种类与特性

国际乒联规定底板中合成纤维材料按厚度不得超过 15%。目前市场上主流的纤维材料包括碳纤维、芳基纤维、Zylon 纤维、玻璃纤维及其混编组合[^7]。

### 3.1 碳纤维（Carbon Fiber）

- **外观**：黑色
- **特性**：强度极高、比重轻、受冲击形变小、恢复速度快
- **典型影响**：增加底板硬度和出球速度，扩大甜区（Sweet Spot），但手感偏硬、持球时间短
- **编织类型**：编织碳（Woven Carbon）、排列碳（Unidirectional Carbon）、短切碳（Chopped Carbon）、颗粒碳（Carbon Powder）

碳纤维是乒乓球底板中最经典的合成材料。编织碳纤维由纵横交错的碳丝编织而成，提供各向同性的强度；排列碳纤维的碳丝呈单一方向排列，仅在纤维方向提供强度，现已逐渐被淘汰。短切碳纤维和颗粒碳材料主要用于中低端底板，能提升弹性但效果有限[^8]。

### 3.2 芳基纤维 / 芳纶纤维（Aramid / Arylate / Kevlar）

- **学名**：聚对苯二甲酰对苯二胺（Poly-para-phenylene terephthalamide）
- **外观**：蓝色（蓝芳）、红色（红芳）、黄色（黄芳）
- **特性**：韧性极强、高粘弹性、形变恢复快、吸震性好
- **典型影响**：提供柔和击球感、延长持球时间、增强底劲和旋转能力

芳基纤维按颜色可分为：
- **蓝芳基**：最常用，韧性强、手感软、底劲突出，常与碳素混编为芳碳（ALC）
- **红芳基**：比重较大、手感最柔和、底劲较弱，多见于全面型或防守型底板
- **黄芳基**：国产底板中较多使用，比蓝芳基更柔软，成本较低，形变恢复快[^9]

Kevlar 是杜邦公司注册的芳纶纤维商标名，属于芳基纤维的一种。

### 3.3 芳基/碳素混编纤维（ALC / Aramid-Carbon）

- **构成**：芳基纤维与碳纤维按一定比例混编织物
- **特性**：综合芳基的柔韧性与碳素的刚性，兼具良好的持球能力和出球速度
- **典型影响**：底劲明显，适合中近台快攻结合弧圈打法

ALC 是目前市场上最为流行的纤维组合之一，代表底板包括 Butterfly Viscaria、Timo Boll Spirit、张继科系列等[^10]。

### 3.4 Zylon 纤维（ZLF / PBO）

- **全称**：聚对苯撑苯并二噁唑（Poly-p-phenylene-2,6-benzobisoxazole）
- **外观**：金色
- **特性**：强度为芳基的 2 倍以上、手感极为柔软、重量更轻、弹性和恢复速度优异
- **典型影响**：提供极高的速度/控制比，手感柔软且力量充沛

ZLF 可单独作为纤维层使用，也可与碳纤维混编为 ZLC。代表底板包括 Butterfly Photino（ZLF）、波尔 ZLC 等[^11]。

### 3.5 ZLC（Zylon + Carbon）

- **构成**：Zylon 纤维与碳纤维混编，通常约 50% Zylon + 50% Carbon
- **特性**：比 ALC 轻 10%–15%，手感更软，甜区与速度保留
- **典型影响**：具有最高的速度/控制比，适合追求手感与速度兼备的进攻型选手

### 3.6 玻璃纤维（Glass Fiber）

- **特性**：强度不高、手感柔和、与纯木最为接近
- **典型影响**：成本低、可稳定手感、降低个体差异
- **用途**：支撑层、用于需要柔和手感的全面型底板

| 纤维类型 | 强度 | 弹性 | 手感柔软度 | 重量 | 吸震性 | 典型用途 |
| :------- | :--: | :--: | :--------: | :--: | :----: | :------- |

## 4 底板层数结构

乒乓球底板的层数结构从 1 层（单桧）到 17 层不等，但最常见的为 5 层和 7 层结构。层数越多、每层越薄，底板通常越硬、速度越快[^12]。

### 4.1 纯木底板

#### 5 层纯木（5-ply All-Wood）

- **典型结构**：面材—力材—大芯—力材—面材（对称结构）
- **特性**：控制好、手感清晰、持球时间长、旋转能力强
- **代表型号**：Stiga OC（蔻头+云杉+阿尤斯）、Butterfly 科贝尔（林巴+林巴+阿尤斯）、亚萨卡 YE
- **适用打法**：弧圈型、全能型

#### 7 层纯木（7-ply All-Wood）

- **典型结构**：面材—力材—次芯—大芯—次芯—力材—面材
- **特性**：板身更硬、出球更快、支撑力更强
- **代表型号**：Stiga Clipper Wood（林巴+阿尤斯×5+林巴）、Butterfly 陈静
- **适用打法**：快攻型、快弧型

### 4.2 纤维复合底板

#### 3+2 结构（3 木 + 2 纤维）

- **典型结构**：面材—纤维—大芯—纤维—面材
- **特性**：板身较厚（6.5–7.4 mm），刚性强、反弹迅速
- **代表型号**：Butterfly 普碳（桧木+碳+桐木大芯）、施碳（加厚版普碳）
- **适用打法**：以速度为核心的快攻型

#### 5+2 结构（5 木 + 2 纤维）—— 当前主流

- **典型结构**：面材—纤维—力材—大芯—力材—纤维—面材
- **特性**：比 3+2 结构多了两层木材层，手感更柔和、持球时间更长
- **代表型号**：Butterfly Viscaria（蔻头+芳碳+阿尤斯+桐木大芯）、波尔 Spirit、张继科 ALC
- **适用打法**：快攻结合弧圈、弧圈快攻

### 4.3 结构类型对比

| 结构类型 | 层数 | 典型厚度 (mm) | 典型重量 (g) | 速度 | 控制 | 甜区 |
| :------- | :-: | :-----------: | :----------: | :--: | :--: | :--: |
| 单桧 | 1 | 8–10 | 80–95 | ★★★ | ★★★★ | ★★ |
| 5 层纯木 | 5 | 5.5–6.5 | 80–90 | ★★★ | ★★★★★ | ★★★ |
| 7 层纯木 | 7 | 6.0–7.0 | 85–95 | ★★★★ | ★★★★ | ★★★ |
| 3+2 碳板 | 5 | 6.5–7.4 | 85–100 | ★★★★★ | ★★★ | ★★★★★ |
| 5+2 芳碳板 | 7 | 5.5–6.2 | 85–95 | ★★★★ | ★★★★ | ★★★★★ |

## 5 纤维内置与外置对性能的影响

纤维层在底板中的位置对性能有显著影响，可分为**外置（Outer）** 与**内置（Inner）** 两类[^13]。

### 5.1 外置纤维（Outer Fiber / Fiber under Veneer）

- **定义**：纤维层位于面材之下、力材之上
- **特性**：出球直接、速度快、手感偏硬、甜区大
- **适合**：注重速度和借力反弹的进攻型选手
- **代表**：Butterfly Viscaria、波尔 ALC（外置）

### 5.2 内置纤维（Inner Fiber / Fiber near Core）

- **定义**：纤维层位于力材之下、大芯之上（或两侧）
- **特性**：保留更多木材手感、持球时间更长、发力后有"额外档位"的加速感
- **适合**：注重旋转和弧线的弧圈型选手
- **代表**：Butterfly Innerforce ZLC（内置）

### 5.3 位置对比

| 参数 | 外置纤维 | 内置纤维 |
| :--- | :------: | :------: |
| 出球速度（小力量） | 快 | 中等 |
| 出球速度（大力量） | 快 | 很快（额外加速） |
| 手感清晰度 | 偏硬、直接 | 柔和、自然 |
| 持球时间 | 短 | 长 |
| 旋转能力 | 中等 | 强 |
| 甜区大小 | 大 | 中等偏大 |

## 6 经典底板的材料结构案例分析

以下列举数款具有代表性的经典底板，分析其材料搭配与结构设计逻辑。

### 6.1 Butterfly Viscaria

| 层位 | 材料 |
| :--- | :--- |
| 面材（第 1、7 层） | Koto（蔻头） |
| 纤维（第 2、6 层） | ALC（芳基碳素编织） |
| 力材（第 3、5 层） | Ayous（阿尤斯） |
| 大芯（第 4 层） | 桐木（Kiri） |
| 总厚度 | 5.8 mm |
| 重量 | 约 87–92 g |

**设计特点**：外置芳碳 + 桐木大芯的黄金组合，攻守均衡，快弧兼备，是 40+ 塑料球时代最成功的底板之一。

### 6.2 Stiga OC（Offensive Classic）

| 层位 | 材料 |
| :--- | :--- |
| 面材（第 1、5 层） | Koto 染色 |
| 力材（第 2、4 层） | 云杉（Spruce） |
| 大芯（第 3 层） | Ayous（阿尤斯） |
| 总厚度 | 约 5.8 mm |
| 重量 | 约 82–88 g |

**设计特点**：经典 5 层纯木弧圈板，云杉力材提供优秀的弹簧效应，阿尤斯大芯提供充沛底劲，是三分台的弧圈利器。

### 6.3 Butterfly 普碳（Primorac Carbon）

| 层位 | 材料 |
| :--- | :--- |
| 面材（第 1、5 层） | 桧木（Hinoki） |
| 纤维（第 2、4 层） | 编织碳（Carbon） |
| 大芯（第 3 层） | 桐木（Kiri） |
| 总厚度 | 7.1 mm |
| 重量 | 约 92–100 g |

**设计特点**：3+2 结构经典代表，碳纤维位于面材之下，刚性强、反弹快。桧木面材提供柔和触感，中和碳素的过硬手感。

## 7 对 Octo 乒乓球拍材料选型的启示

结合[侏儒症患者手部尺寸与握力特征研究报告](%E4%BE%8F%E5%84%92%E7%97%87%E6%82%A3%E8%80%85%E6%89%8B%E9%83%A8%E5%B0%BA%E5%AF%B8%E4%B8%8E%E6%8F%A1%E5%8A%9B%E7%89%B9%E5%BE%81%E7%A0%94%E7%A9%B6%E6%8A%A5%E5%91%8A.md)的研究数据，Octo 乒乓球拍的材料选型应重点关注以下方向：

### 7.1 减重策略

| 措施 | 预期减重 | 注意事项 |
| :--- | :------: | :------- |
| 采用轻质大芯（桐木） | 10–15 g | 需配合纤维层保证刚度 |
| 选用薄板面设计（5.0–5.5 mm） | 5–10 g | 过薄可能影响持球感和强度 |
| 使用轻质纤维（ZLF/ZLC 替代传统碳纤维） | 5–10 g | 成本增加，但手感更优 |
| 减短握柄长度至 60–75 mm | 3–5 g | 配合掌宽 <7 cm 的握持需求 |

### 7.2 重心后移策略

- 可在大芯中使用**梯度密度设计**（拍头侧采用密度较低的轻木/Ayous，拍柄侧集成配重）
- 握柄内部设计**空腔或可调配重舱**，允许用户根据个人臂长和力量调节平衡点

### 7.3 手感与支撑平衡

- 推荐采用 **5+2 外置结构** 或 **内置纤维结构**，在保证足够支撑力的同时，通过纤维层的优化选择降低整体重量
- 考虑使用 **ZLF 或 ALC 纤维**替代传统纯碳纤维，以获取更柔和的手感和更好的旋转能力，降低振动传递对上肢关节的冲击

## 8 结论

本报告系统梳理了乒乓球拍底板中使用的天然木材（桧木、桐木、阿尤斯、林巴、蔻头、云杉等）和合成纤维材料（碳纤维、芳基纤维、ALC、ZLC、ZLF、玻璃纤维等）的种类、性能特征及典型应用结构。主要结论如下：

1. **天然木材按层位分工明确**：面材决定触球手感（桧木柔和、蔻头硬脆、林巴持球好）；力材提供支撑和弹性（云杉弹簧效应、阿尤斯韧性强）；大芯决定底板底劲和重量（桐木轻透、阿尤斯形变强）。

2. **纤维材料提供性能扩展**：碳纤维提升速度和甜区；芳基纤维增加持球时间和旋转；ALC/ZLC 等混编纤维综合二者优点，是当前主流选择。

3. **层数结构与纤维位置决定性能取向**：5+2 外置芳碳结构是当前 40+ 塑料球时代的主导设计，兼顾速度、旋转与控制。

4. **针对 Octo 项目的轻量化需求**，建议优先考虑桐木大芯 + 轻质纤维（ZLF/ALC）的组合方案，并通过握柄减短、板厚优化、梯度密度等设计手段进一步降低总重量至 110–130 g 的目标范围。

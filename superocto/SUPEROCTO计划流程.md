# SUPER O C T O 实施计划流程

> **项目定位**：作为 Octo 项目的**并行技术探索分支**，利用 3D 打印人造木（Wood PLA）与晶格结构，实现极致轻量乒乓球拍的一体化设计与快速迭代。
> **规则状态**：❌ 不符 ITTF 竞赛规则（见[SUPEROCTO > 第 1 节](../SUPEROCTO.md#第%201%20节)），定位为训练拍、技术原型与展示项目。
> **总目标**：在 3–5 轮迭代内，实现成品总重 ≤115 g 的 3D 打印一体化球拍，并评估其与方案一/二/三的手感差异。

## 2 Phase 0：设备就绪与基础验证

### 2.1 目标
- 确认 3D 打印机状态正常，能够稳定打印 Wood PLA 材料
- 打印标准测试样块，建立基础打印参数基线
- 熟悉 Wood PLA 的打印特性与后处理基础操作

### 2.2 子任务

| 编号 | 任务 | 输出物 | 预计耗时 |
| :--- | :--- | :----- | :------: |
| 0.1 | 设备状态检查与校准（调平、挤出门清理、热床附着力测试） | 设备运行正常确认 | 1–2 h |
| 0.2 | 采购 Wood PLA 线材（建议 eSUN Wood PLA 或 Amolen Wood PLA，1 kg） | 线材到货 | 1–3 天（物流） |
| 0.3 | 打印 20×20×20 mm 立方体测试块（100% 填充），验证尺寸精度与层间附着力 | 精度测量数据 | 1 h |
| 0.4 | 打印 50×50×5 mm 薄板（100% 填充 + 不同填充图案各一），评估表面质量与填充一致性 | 填充图案对比样片 | 2–3 h |
| 0.5 | 对测试样块进行基础后处理（打磨 #120 → #240 → #400），初步感受 Wood PLA 加工性 | 后处理经验记录 | 1 h |
| 0.6 | **记录所有打印参数**（温度、速度、层高、流量补偿等），建立参数日志 | 打印参数日志（`打印参数日志.md`） | 30 min |

### 2.3 关键决策点 — Gate 0

| 检查项 | 通过标准 |
| :----- | :------- |
| 打印机精度 | 20 mm 立方体实测尺寸偏差 ≤ ±0.2 mm |
| 层间附着力 | 人工弯折测试样块，不断裂或分层 |
| Wood PLA 打印稳定性 | 连续打印 2 h 无堵头、无拉丝、无翘边 |
| 后处理可行性 | 打磨后表面光滑无明显层纹，木质感真实 |

> ⚠️ **如果 Gate 0 未通过**：排查打印机问题或更换线材品牌，不进入 Phase 1。

## 3 Phase 1：3D 模型设计与切片参数设定

### 3.1 目标
- 完成乒乓球拍的 3D 参数化模型设计（或基于现有模型修改）
- 确定切片策略（填充图案、壁厚、密度梯度、打印方向）
- 输出打印就绪的 G-code 文件

### 3.2 子任务

| 编号 | 任务 | 输出物 | 预计耗时 |
| :--- | :--- | :----- | :------: |
| 1.1 | **建模**：在 CAD 软件（Fusion 360 / SolidWorks / FreeCAD）中建立乒乓球拍 3D 模型 | `.stl` / `.step` 文件 | 4–8 h |
| 1.2 | 设计参数化（拍面尺寸、总厚度、握柄形状等需可调节），便于后续迭代 | 参数化设计文件 | — |
| 1.3 | 确定打印方向（推荐拍面水平放置，Z 轴为厚度方向） | 打印方向选定 | 30 min |
| 1.4 | **切片参数设定**（Orca Slicer / Bambu Studio / Prusa Slicer）： | 切片配置文件 `.3mf` | 2–4 h |
| | — 填充图案：拍面 Gyroid，握柄 Gyroid，甜区加强 Triangle | | |
| | — 填充率梯度：拍面 22% → 过渡区 22→15% → 握柄 15% | | |
| | — 壁厚：拍面上下面各 0.6 mm（实体层），握柄全周 0.4 mm | | |
| | — 层高：拍面 0.12 mm，握柄 0.20 mm | | |
| | — 打印速度：40–50 mm/s | | |
| 1.5 | 估算切片重量，与[SUPEROCTO > 3.3 重量估算](../SUPEROCTO.md#3.3%20重量估算)理论值对比 | 切片重量预估 | 15 min |
| 1.6 | 输出 V1.0 版 G-code，准备打印 | `octo_v10.gcode` | 10 min |

### 3.3 模型设计要点

```
┌──────────────────────────────────┐
│  拍面（整体厚度 4.0 mm）          │
│  ┌───────────────────────────┐    │
│  │ 顶层实体（0.6 mm）          │    │  ← 100% 填充，模拟面材
│  ├───────────────────────────┤    │
│  │ Gyroid 填充层（2.8 mm）     │    │  ← 22% 填充，主减重区
│  │ ┌─甜区加强───┐              │    │
│  │ │ Triangle │              │    │  ← 甜区下方 35% 填充
│  │ └───────────┘              │    │
│  ├───────────────────────────┤    │
│  │ 底层实体（0.6 mm）          │    │  ← 100% 填充，底面
│  └───────────────────────────┘    │
│  ↕ 渐变过渡区（5.0 mm）           │
│  ┌───────────────────────────┐    │
│  │ 握柄实体表皮（0.4 mm 全周）   │    │
│  │ ┌─────────────────────────┐│   │
│  │ │ Gyroid 芯（15%）         ││   │  ← 极轻握柄
│  │ └─────────────────────────┘│   │
│  └───────────────────────────┘    │
└──────────────────────────────────┘
```

> **参数化变量**：将拍面厚度、填充率、壁厚、甜区加强范围等设置为可调参数，后续迭代只需修改数值重新切片即可，无需重建模型。

### 3.4 关键决策点 — Gate 1

| 检查项 | 通过标准 |
| :----- | :------- |
| 模型完整性 | 模型水密（watertight），无翻转法线，STL 网格无自交 |
| 切片重量偏差 | 切片预估重量与理论值偏差 ≤ ±5 g |
| 打印方向合理 | 支撑结构极少或无支撑，热床附着面积充足 |
| 文件可迭代 | 参数化变量已定义，后续可数值修改 |

## 4 Phase 2：材料选型与打印参数调优

### 4.1 目标
- 对比不同品牌/规格的 Wood PLA 线材，确定最佳材料
- 打印标准力学样条，获取材料的实际力学性能
- 确定最优打印参数组合（温度、速度、层高、流量补偿）

### 4.2 子任务

| 编号 | 任务 | 输出物 | 预计耗时 |
| :--- | :--- | :----- | :------: |
| 2.1 | 准备 2–3 种 Wood PLA 线材样本（不同品牌/木粉含量） | 线材样本 | 2–5 天（物流） |
| 2.2 | 对每种线材打印 **层间附着力测试样条**（ISO 527 标准哑铃型或自定义扁平条） | 拉伸测试数据 | 2–3 h/种 |
| 2.3 | 对每种线材打印 **三点弯曲样条**（80×10×4 mm），评估弯曲刚度与断裂模式 | 弯曲模量数据 | 2 h/种 |
| 2.4 | 打印 **密度渐变辨识样板**（10×10 cm，填充率从 10% 到 40% 渐变），直观感受重量-硬度关系 | 手感辨识样板 | 3 h |
| 2.5 | 优化打印参数：对比不同温度（195/200/205/210 °C）、层高（0.10/0.12/0.16/0.20 mm）、速度（30/40/50 mm/s）的表面质量 | 最佳参数组合 | 4–6 h |
| 2.6 | **记录所有测试结果**，更新材料参数数据库 | `材料对比测试记录.md` | 1 h |

### 4.3 材料对比评价矩阵

| 评价维度 | 权重 | 说明 |
| :------- | :--: | :--- |
| 打印稳定性 | 30% | 无堵头、无拉丝、无翘边、层间附着力好 |
| 表面质感 | 25% | 打磨后木纹真实度、均匀度 |
| 强度/韧性 | 20% | 三点弯曲不断裂、层间不开裂 |
| 价格可及性 | 15% | 每公斤价格、购买便利性 |
| 后处理适配性 | 10% | 打磨、上色、涂油的易用性 |

### 4.4 关键决策点 — Gate 2

| 检查项 | 通过标准 |
| :----- | :------- |
| 线材选定 | 选出综合评分最高的 1 种线材，全程使用 |
| 打印参数窗口 | 确定温度、速度、层高组合，保证连续 10 h 打印无故障 |
| 密度-硬度关系数据 | 获得填充率与弯曲刚度之间的可预测关系曲线 |

## 5 Phase 3：初始原型打印与手感评估

### 5.1 目标
- 打印 V1.0 初始原型底板（参数按[SUPEROCTO > 3.2 参数表](../SUPEROCTO.md#3.2%20参数表)设定）
- 完成基础后处理（打磨 + 涂油）
- 进行主观手感评估，记录定性反馈
- 贴附测试套胶，称量成品总重并测量重心位置

### 5.2 子任务

| 编号 | 任务 | 输出物 | 预计耗时 |
| :--- | :--- | :----- | :------: |
| 3.1 | 打印 V1.0 底板（预计 6–8 h） | 打印完成的底板毛坯 | 6–8 h |
| 3.2 | 基础后处理：#120 → #240 → #400 打磨 → 木蜡油 / 哑光清漆 2 层 | 处理后底板 | 2 h（分两次） |
| 3.3 | 称重（裸板），记录实际重量，与切片预估/理论值对比 | 实际重量数据 | 10 min |
| 3.4 | 测量重心位置（从拍柄末端起算） | 重心位置数据 | 10 min |
| 3.5 | 贴附测试套胶（两面相同套胶，建议使用已裁切的旧套胶或廉价训练套胶） | 可试打球拍 | 30 min |
| 3.6 | **主观手感评估**： | 手感评估记录 | 1–2 h |
| | — 握持舒适度（握柄尺寸、重心位置） | | |
| | — 空挥感受（挥拍惯性、拍头沉/轻感） | | |
| | — 对墙击球或发球机测试（反弹手感、声音、甜区响应） | | |
| 3.7 | 与[三套底板设计方案及采购清单](../%E9%98%B6%E6%AE%B52-%E8%B0%83%E7%A0%94%E4%BB%A5%E5%8F%8A%E6%9D%90%E6%96%99%E5%87%86%E5%A4%87/%E4%B8%89%E5%A5%97%E5%BA%95%E6%9D%BF%E8%AE%BE%E8%AE%A1%E6%96%B9%E6%A1%88%E5%8F%8A%E9%87%87%E8%B4%AD%E6%B8%85%E5%8D%95.md)中方案一/二/三的预期手感进行定性对比 | 横向对比初判 | 30 min |
| 3.8 | 记录所有发现，更新迭代需求清单 | 迭代需求清单 | 30 min |

### 5.3 手感评估指标

| 评估项目 | 评价方法 | 记录方式 |
| :------- | :------- | :------- |
| **整体重量感** | 空挥 + 对墙击球，对比常规球拍 | 1–5 分 + 文字描述 |
| **握持舒适度** | 持续握持 5 min，评估疲劳感 | 1–5 分 + 文字描述 |
| **击球手感** | 对墙击球 50 次，感受反弹力与振动 | 偏硬/偏软/适中 + 文字描述 |
| **甜区大小** | 逐点敲击法，感受甜区分布 | 甜区直径估计 (mm) |
| **声音反馈** | 击球时球拍声音（清脆/沉闷） | 文字描述 |
| **重心感受** | 空挥 + 正反手转换 | 头重/均衡/头轻判断 |

### 5.4 关键决策点 — Gate 3

| 检查项 | 通过标准 |
| :----- | :------- |
| 底板可正常使用 | 无结构缺陷（开裂、分层、变形） |
| 重量符合预期 | 裸板实际重量 ≤ 55 g（偏差 ≤ ±3 g） |
| 重心位置可接受 | 重心距拍柄末端 ≤ 120 mm |
| 握柄尺寸舒适 | 握柄周长 ≤ 80 mm，长度 ≤ 70 mm（参考[侏儒症患者手部尺寸研究报告](../%E9%98%B6%E6%AE%B51-%E5%89%8D%E7%BD%AE%E5%87%86%E5%A4%87/%E4%BE%8F%E5%84%92%E7%97%87%E6%82%A3%E8%80%85%E6%89%8B%E9%83%A8%E5%B0%BA%E5%AF%B8%E7%A0%94%E7%A9%B6%E6%8A%A5%E5%91%8A.md)） |

> ⚠️ **如果 Gate 3 未通过**：根据具体问题返回 Phase 1（模型修改）或 Phase 2（参数调整）。

## 6 Phase 4：参数迭代与手感调校

### 6.1 目标
- 基于 Phase 3 的手感反馈，制定参数调节策略
- 打印 2–4 个参数变体版本（不同填充率、壁厚、甜区设计）
- 进行对比手感评估，锁定最优参数组合
- 如有条件，邀请用户（侏儒症患者）参与主观评估

### 6.2 参数调节策略

根据[SUPEROCTO > 6 晶格结构的手感调校](../SUPEROCTO.md#6%20晶格结构的手感调校)建议，推荐以下调校路线：

#### 调校方向 1：硬度调节

| 版本 | 填充率 | 实体层厚 | 预估重量变化 | 手感预期 |
| :--- | :----: | :------: | :----------: | :------- |
| V1.0（基础） | 22% | 0.6 mm | — | 基线参考 |
| V1.1（软版） | 18% | 0.5 mm | −4~5 g | 更软，更吸振 |
| V1.2（硬版） | 28% | 0.7 mm | +5~6 g | 更硬，反弹更强 |

#### 调校方向 2：重心调节

| 版本 | 握柄填充率 | 拍面填充率 | 重心变化方向 |
| :--- | :--------: | :--------: | :----------- |
| V1.0 | 15% | 22% | 基线 |
| V2.0（头轻） | 20% | 18% | 向握柄移动 ~5 mm |
| V2.1（头重） | 10% | 25% | 向拍头移动 ~5 mm |

#### 调校方向 3：甜区优化

| 版本 | 甜区加强范围 | 加强填充率 | 效果 |
| :--- | :----------: | :--------: | :--- |
| V1.0 | 直径 40 mm | 35% | 基线 |

## 7 Phase 5：后处理工艺定型与耐久性测试

### 7.1 目标

| 测试项目 | 通过标准 |

## 10 风险预案

### 10.1 技术风险

| 风险 | 概率 | 影响 | 预案 |
| :--- | :--: | :--: | :--- |
| **Wood PLA 堵头/打印失败** | 中 | 高 | ① 改用大直径喷嘴（0.6 mm）降低堵头风险 ② 备有另一品牌线材 ③ 打印前烘干线材（Wood PLA 易吸潮） |
| **层间剥离** | 中 | 高 | ① 增加壁厚（4 层 → 6 层） ② 提高热床温度（60→70 °C）改善层间附着 ③ 调整打印方向使主应力方向平行于层面 |
| **翘边/变形** | 中 | 中 | ① 使用 Brim（8 mm） ② 封闭箱体或使用挡风罩 ③ 降低打印速度 |
| **尺寸偏差（握柄过紧/过松）** | 低 | 中 | ① 打印前检查流量补偿 ② 打印适配性测试环（只打印握柄截面的小样检查尺寸） |
| **晶格手感无法接受** | 中 | 高 | ① 在 Phase 2 中先打印手感辨识样板，提前评估 ② 尝试混合制造（3D 打印大芯 + 天然木皮热压） |

### 10.2 进度风险

| 风险 | 影响 | 预案 |
| :--- | :--: | :--- |
| **打印机故障（长时间维修）** | 高 | ① 准备备用打印方案（联系学校或创客空间） ② 或暂停方案四，优先推进方案一/二/三 |
| **线材采购延迟** | 中 | ① 提前下单，预留 5–7 天物流余量 ② 选择淘宝/京东等快速物流渠道 |
| **手感评估需要更多迭代** | 中 | ① Phase 4 预留了 2–4 次迭代的余量 ② 可在 Phase 4 之后加开 Phase 4b（额外迭代） |

### 10.3 退出条件

如果以下任一条件满足，**应终止方案四**，将资源集中在方案一/二/三：

1. **Phase 3 初始原型重量 > 60 g**，且通过参数优化无法降至 55 g 以下
2. **Phase 3 手感评估总分 < 2/5**，且无明确的调校改进方向
3. **连续 3 次打印失败**（堵头、翘边、分层等），且无法通过参数调整解决
4. **打印机维修时间 > 2 周**，且无法找到替代打印设备

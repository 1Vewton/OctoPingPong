## 背景
乒乓球作为一项对场地要求相对灵活、运动强度可调节的运动，非常适合特殊群体进行康复训练和日常锻炼。然而，市面上主流的乒乓球拍均基于普通成年人的手部尺寸（掌宽约 8-10cm，握柄周长约 8-12cm）和力量标准设计。

对于侏儒症患者（通常指成年后身高低于 147cm，手部尺寸、臂长及肌肉力量均显著小于常人的群体）而言，现有球拍存在以下痛点：
1. 重量过载：标准球拍重量通常在 170g-200g 之间，对于手部力量较小的患者，挥拍惯性大，易造成手腕及肘关节劳损。
2. 握柄不适：标准握柄过粗、过长，患者难以"正手利"或"反手利"灵活转换，甚至无法完全握住手柄，存在脱手风险。
3. 重心失衡：普通球拍重心靠近拍头，对于臂长较短的患者，力矩效应被放大，操控难度显著增加。
## 目标
本项目Octo乒乓球拍旨在设计一款专为侏儒症患者定制的乒乓球拍，核心目标是轻量化: 
1. 减重目标：将成品球拍总重控制在110g - 130g之间（比标准球拍减重 30%-40%），降低运动中的关节负荷。
2. 握持优化：设计可调节或超细短柄结构，适配掌宽 <7cm 的用户，确保握持稳固且转换灵活。
3. 重心后移：通过材料与结构设计，将球拍平衡点向拍柄方向移动，减小转动惯量，提升操控灵敏度。
